# model_input (runtime)

Derived from the synthetic Attack Path Compiler dataset:

`attack_path_dataset/attack_path_dataset/data/model_input`

`scenarioIntelligence.json` is a compact per-scenario inventory built only from
`scenarios.jsonl`, `events.jsonl` (distinct `source` values), and
`interventions.jsonl`. **`data/ground_truth` is never read at runtime.**

All records are synthetic.

`scenario_graph/*.json` contains the runtime-safe, per-scenario projection of
`assets.jsonl`, `relationships.jsonl`, `events.jsonl`, and `evidence.jsonl`.
It is generated by `scripts/build-scenario-graph-data.mjs` and loaded on demand
by the 3D graph. No ground-truth files are included or consulted.
